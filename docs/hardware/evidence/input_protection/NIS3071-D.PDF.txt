  The NIS3071 is a 4−channel, 60 V, 2.5 A per channel eFuse which
protects downstream loads from output  shorts, overloads and
overcurrent events. Each channel is in a high−side configuration, and            MARKING DIAGRAMS
is independently controlled by its corresponding enable pins. The
NIS3071 communicates status via a common active−low fault pin.
This eFuse features an internal soft start delay, trip time control, and an                   XXXXXXXX
                                                                       XXXXXXXX
adjustable current limit setting common to all channels. The NIV3071                                                               AWLYYWW
is an automotive−grade, AEC−Q100 qualified, pin−to−pin equivalent
of the NIS3071.
